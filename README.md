# shishka-nedocad
## Техническое задание
### Стек
- PHP + SQLite (бэкенд, CRUD через JSON API)
- HTML/CSS/JS (фронт)
- SVG для схемы

### Веб-страницы:
1. Список объектов (нод)
- просто вывод списка объектов из БД (ПК, коммутаторы, маршрутизаторы);
- нижняя строка всегда пустая, ее можно заполнить и добавить новый объект в БД
2. Справочник моделей
- просто вывод списка моделей из БД (Cisco-1111,DLINK-2222 и т.п.)
- нижняя строка всегда пустая, ее можно заполнить и добавить новую модель в БД
3. Связи 
- просто вывод списка связей из БД (ПК1---ПК2; ПК2---КОМ1 и т.п.)
4. Схема
- основная рабочая область с JS, где отрисовывается схема с учетом БД и заданных параметров пользователя

## Автоматическое создание связей
По кнопке «Автосвязи»:
- Для каждого pc/printer найти switch_access с тем же номером кабинета (из парсинга имени). Если нет — создать коммутатор доступа с именем SW-<кабинет>. Создать связь.
- Для каждого switch_access найти switch_dist с любым (или по настройкам) — создать связь.
- Для каждого switch_dist найти router — создать связь.

## Страница схемы
- Отображение SVG (ширина 1920, высота 1080, но окно браузера может быть меньше — скролл и масштабирование).
- Группировка по кабинетам (опционально, чекбокс): пунктирная рамка вокруг устройств одного кабинета.
- Layout: колонками по rank (лево → право). Внутри колонки — вертикальный список. Если включена группировка, внутри рамки кабинета — вертикальный список устройств.
- Размер прямоугольника: берётся из модели (width×height). Текст-номер: над прямоугольником, шрифт 8pt. Содержимое: если имя распарсилось как кабинет-номер — выводится только номер (часть после -). Иначе — первые 6 символов имени.
- Линии: от правой границы узла к левой границе целевого узла, горизонталь + вертикаль (один излом). Без пересечений не гарантируется, но алгоритм минимизирует.
- Кнопка «Экспорт PDF» — вызов браузерной печати с CSS для A4 landscape.
- Минимальный размер окна для работы: 800×800 (интерфейс адаптируется, схема скроллится).
